Section 1 of 18

Your role and the goal

You are a senior Python / data engineer. Build, from an empty folder, a complete, working Retrieval-Augmented Generation (RAG) system for clinical / medical nutrition textbooks, called RAG11 Nutrition.

The finished system must:

  1. Turn a folder of nutrition-textbook PDFs into hierarchical chunks (big "parent" section chunks + small "child" retrieval chunks).
  2. Embed the child chunks with Voyage AI and store everything in Supabase (Postgres + pgvector).
  3. Verify that what is in the database matches what is on disk, exactly.
  4. Answer nutrition questions with Claude, strictly grounded in retrieved textbook excerpts, returning a short Yes/No line (when the question has a clean yes/no answer), a full explanation, and the textbook page numbers that back the answer.
  5. Offer five pluggable retrieval upgrades on top of plain vector search: hybrid search (dense + keyword, fused with Reciprocal Rank Fusion), reranking, parent-chunk expansion ("small-to-big"), HyDE (hypothetical document embeddings) and multi-query / question splitting, each demonstrated in its own notebook with three real nutrition questions.
  6. Ship a fully offline unit-test file (fake clients, no network), documentation, and a one-command "save to GitHub" helper.

Work through the sections below in order. Everything you need (schema, constants, prompts, function contracts, gotchas) is in this document. Where this document gives exact code, reproduce it faithfully; where it gives a contract, implement the contract.

Data hierarchy (three levels, one owner per tree):

  • source = one PDF (root of its own tree; owns itself).
  • parent chunk = one section of that PDF (title, page range, full section text).
  • child chunk = a small window of a parent's text (what actually gets embedded and searched).

  • Ask the user (once, up front) for: Supabase project URL + keys, Voyage API key, Anthropic API key, and where the PDFs are (a shared Google Drive folder URL or a local folder).   • Every notebook cell carries a visible number: markdown cells start with **Cell #NN**, code cells start with a # Cell #NN comment (a %%sql-style magic cell keeps the magic on line 1 and gets -- Cell #NN at the end). Provide add_cell_numbers.py (see section 15) to (re)apply this numbering.

Supabase schema — sql/create_sql_tables.sql

The user runs this once in the Supabase Dashboard → SQL Editor. It must be idempotent (safe to re-run). All three tables share the same five-column pattern:

Column Meaning
rowGUID unique id (uuid, primary key)
rowOwnerGUID the row's ultimate owner = the owning source's rowGUID (a real foreign key). For a source row it equals its own rowGUID
rowParentGUID hierarchical link: child → its parent chunk's rowGUID; null for sources and parent chunks
orderInList position within the owning list
rowJSON the full payload, verbatim from the JSON file the chunker wrote to disk (single source of truth)

A few columns are generated always as (...) stored pulled out of rowJSON, so filters/joins need no jsonb operators and can never drift from rowJSON.

create extension if not exists vector with schema extensions;

-- 1. Sources: one row per PDF (owns itself, has no parent)
create table if not exists public.rag11_data_sources (
    "rowGUID"       uuid primary key default gen_random_uuid(),
    "rowOwnerGUID"  uuid not null,
    "rowParentGUID" uuid,
    "orderInList"   int not null,
    "rowJSON"       jsonb not null,
    source_key    text generated always as ("rowJSON"->>'source_key') stored,
    filename      text generated always as ("rowJSON"->>'filename') stored,
    drive_file_id text generated always as ("rowJSON"->>'drive_file_id') stored,
    structure     text generated always as ("rowJSON"->>'structure') stored,
    created_at timestamptz not null default timezone('utc', now()),
    constraint rag11_data_sources_self_owned check ("rowOwnerGUID" = "rowGUID"),
    constraint rag11_data_sources_no_parent  check ("rowParentGUID" is null)
);
create unique index if not exists uq_rag11_sources_order      on public.rag11_data_sources ("orderInList");
create unique index if not exists uq_rag11_sources_source_key on public.rag11_data_sources (source_key);

-- 2. Parents: one row per section
create table if not exists public.rag11_chunks_parent_table (
    "rowGUID"       uuid primary key default gen_random_uuid(),
    "rowOwnerGUID"  uuid not null references public.rag11_data_sources("rowGUID") on delete cascade,
    "rowParentGUID" uuid,
    "orderInList"   int not null,
    "rowJSON"       jsonb not null,
    source     text generated always as ("rowJSON"->>'source') stored,
    source_key text generated always as ("rowJSON"->>'source_key') stored,
    title      text generated always as ("rowJSON"->>'title') stored,
    start_page int  generated always as (("rowJSON"->>'start_page')::int) stored,
    end_page   int  generated always as (("rowJSON"->>'end_page')::int) stored,
    created_at timestamptz not null default timezone('utc', now())
);
create unique index if not exists uq_rag11_parent_owner_order on public.rag11_chunks_parent_table ("rowOwnerGUID", "orderInList");
create index        if not exists idx_rag11_parent_owner      on public.rag11_chunks_parent_table ("rowOwnerGUID");

-- 3. Children: one row per embeddable chunk + its embedding
create table if not exists public.rag11_chunks_child_table (
    "rowGUID"       uuid primary key default gen_random_uuid(),
    "rowOwnerGUID"  uuid not null references public.rag11_data_sources("rowGUID") on delete cascade,
    "rowParentGUID" uuid not null references public.rag11_chunks_parent_table("rowGUID") on delete cascade,
    "orderInList"   int not null,
    "rowJSON"       jsonb not null,
    source_key  text generated always as ("rowJSON"->>'source_key') stored,
    chunk_text  text generated always as ("rowJSON"->>'text') stored,
    token_count int  generated always as (("rowJSON"->>'token_count')::int) stored,
    embedding   extensions.vector(1024),
    -- Full-text vector for keyword search. Built from "rowJSON"->>'text', NOT from chunk_text:
    -- Postgres generated columns cannot reference other generated columns (error 42P17).
    chunk_tsv   tsvector generated always as (to_tsvector('english', coalesce("rowJSON"->>'text', ''))) stored,
    created_at  timestamptz not null default timezone('utc', now())
);
-- For databases created before chunk_tsv existed ("create table if not exists" won't add columns):
alter table public.rag11_chunks_child_table
    add column if not exists chunk_tsv tsvector
    generated always as (to_tsvector('english', coalesce("rowJSON"->>'text', ''))) stored;

create unique index if not exists uq_rag11_child_parent_order on public.rag11_chunks_child_table ("rowParentGUID", "orderInList");
create index        if not exists idx_rag11_child_owner       on public.rag11_chunks_child_table ("rowOwnerGUID");
create index        if not exists idx_rag11_child_parent      on public.rag11_chunks_child_table ("rowParentGUID");
create index if not exists idx_rag11_child_embedding_hnsw
    on public.rag11_chunks_child_table using hnsw (embedding vector_cosine_ops) with (m = 16, ef_construction = 64);
create index if not exists idx_rag11_child_chunk_tsv_gin
    on public.rag11_chunks_child_table using gin (chunk_tsv);

-- 4. Dense search RPC. Drop stale overloads FIRST: "create or replace" only replaces an EXACT signature,
--    and two overloads make PostgREST fail with PGRST203 "Could not choose the best candidate function".
drop function if exists public.match_rag11_child_chunks(extensions.vector, int, text);
drop function if exists public.match_rag11_child_chunks(extensions.vector, int);

create or replace function public.match_rag11_child_chunks(
    query_embedding extensions.vector(1024),
    match_count     int  default 8,
    filter_owner    uuid default null          -- a rag11_data_sources.rowGUID
)
returns table ("rowGUID" uuid, "rowParentGUID" uuid, "rowOwnerGUID" uuid, "orderInList" int, "rowJSON" jsonb, cosine_distance float)
language sql stable as $$
    select c."rowGUID", c."rowParentGUID", c."rowOwnerGUID", c."orderInList", c."rowJSON",
           (c.embedding <=> query_embedding) as cosine_distance
    from public.rag11_chunks_child_table c
    where c.embedding is not null
      and (filter_owner is null or c."rowOwnerGUID" = filter_owner)
    order by c.embedding <=> query_embedding asc
    limit least(match_count, 50);              -- hard cap: pools > 50 are silently clipped
$$;

-- 5. Keyword (full-text) RPC. websearch_to_tsquery accepts search-engine style input.
drop function if exists public.match_rag11_child_chunks_keyword(text, int, uuid);

create or replace function public.match_rag11_child_chunks_keyword(
    query_text   text,
    match_count  int  default 8,
    filter_owner uuid default null
)
returns table ("rowGUID" uuid, "rowParentGUID" uuid, "rowOwnerGUID" uuid, "orderInList" int, "rowJSON" jsonb, text_rank float)
language sql stable as $$
    select c."rowGUID", c."rowParentGUID", c."rowOwnerGUID", c."orderInList", c."rowJSON",
           ts_rank_cd(c.chunk_tsv, websearch_to_tsquery('english', query_text)) as text_rank
    from public.rag11_chunks_child_table c
    where c.chunk_tsv @@ websearch_to_tsquery('english', query_text)
      and (filter_owner is null or c."rowOwnerGUID" = filter_owner)
    order by text_rank desc
    limit least(match_count, 50);
$$;

-- 6. Fetch one parent row (convenience RPC)
create or replace function public.get_rag11_parent(p_row_guid uuid)
returns public.rag11_chunks_parent_table
language sql stable as $$
    select * from public.rag11_chunks_parent_table where "rowGUID" = p_row_guid;
$$;

9.1 What the notebook does (cell by cell)

  1. Title/description markdown, then %pip install -q -r requirements.txt.
  2. Config cell. Imports; PROJECT_ROOT, INPUT_ROOT = stage1_eda_input, OUTPUT_ROOT = stage1_eda_output, SOURCES_MANIFEST_DIR = OUTPUT_ROOT/"sources". Constants: - MAX_NUMBER_OF_PAGES_TO_USE — smoke-test cap, read from .env via env.optional_env_limit(name, default) (unset or blank gives 100; NONE/ALL/FULL/UNLIMITED/0 gives None = no cap; a positive integer is the cap; anything else raises; document it in .env.sample as MAX_NUMBER_OF_PAGES_TO_USE=100) on how many leading pages get their text extracted per source (section boundaries still come from the full PDF's outline/regex, so they stay correct; sections that start past the cap just get empty text). Set NONE in .env for the real full run (restart the kernel after editing .env). Cache file names include the cap (_cache_pages_max100.json vs _cache_pages.json) so a capped and a full run never reuse each other's cache. - GOOGLE_DRIVE_SOURCES_FOLDER = the shared folder URL (ask the user; the original used a public folder). DRIVE_FOLDER_ID parsed with regex /folders/([a-zA-Z0-9_-]+). - RAG11_UUID_NAMESPACE = uuid.uuid5(uuid.NAMESPACE_DNS, "rag11.nutrition.poc") and deterministic_uuid(key) = str(uuid.uuid5(RAG11_UUID_NAMESPACE, key)). If the installed gdown has no skip_download (raises TypeError), fall back to downloading into a temp dir just to list names (then file_id is None). Raise a clear error if the folder is empty (check it is shared "Anyone with the link").
  4. Source ordering and skipping. KNOWN_SOURCE_EDA_META (from the packages registry) fixes the historical source1..N slot of every known filename; any new file is appended afterwards sorted by name. Files listed in SKIPPED_FILENAMES (known-bad downloads, e.g. a saved HTML page instead of a PDF) are filtered out before slots are assigned. Build SOURCES = {"source1": {file_id, filename, expected_pages, structure, row_guid}, ...} with row_guid = deterministic_uuid(f"source:{file_id or filename}"). def token_len(text: str) -> int:

def build_child_chunks(text: str, target_tokens: int = 400, overlap_pct: float = 0.125) -> list[str]:
    tokens = _ENC.encode(text)
    if not tokens:
        return []
    step = max(1, int(target_tokens * (1 - overlap_pct)))   # 350
    chunks, start = [], 0
    while start < len(tokens):
        end = min(start + target_tokens, len(tokens))
        chunks.append(_ENC.decode(tokens[start:end]))
        if end == len(tokens):
            break
        start += step
    return chunks

import random
import time
from typing import Callable, Optional, TypeVar

T = TypeVar("T")

def with_retry(fn: Callable[..., T], *args, max_attempts: int = 5, base_delay: float = 2.0,
               is_retryable: Optional[Callable[[Exception], bool]] = None, **kwargs) -> T:
    last_exc: Optional[Exception] = None
    for attempt in range(1, max_attempts + 1):
        try:
            return fn(*args, **kwargs)
        except Exception as e:  # deliberately broad: network calls fail in many ways
            last_exc = e
            if is_retryable is not None and not is_retryable(e):
                raise
            if attempt == max_attempts:
                break
            sleep_s = base_delay * (2 ** (attempt - 1)) + random.uniform(0, 0.5)
            print(f"[retry] {getattr(fn, '__name__', fn)} attempt {attempt} failed ({e}); retrying in {sleep_s:.1f}s")
            time.sleep(sleep_s)
    assert last_exc is not None
    raise last_exc

    groups: "OrderedDict[Any, List[dict]]" = OrderedDict()
    for row in rows:
        groups.setdefault(key_fn(row), []).append(row)
    return groups

def first_occurrence_map(rows: List[dict], key: KeyFn) -> "OrderedDict[Any, dict]":
    """Map each distinct key to the FIRST row that had it ("first occurrence wins")."""
    return OrderedDict((k, group[0]) for k, group in group_by_key(rows, key).items())

hybrid_search.py (dense + keyword, fused with Reciprocal Rank Fusion)

Why: embeddings match meaning and can bury the chunk containing the exact number/term ("0.8 g/kg", "PDCAAS"); full-text search matches literal words. Run both over a wide pool and fuse.

import re
import string
from typing import Dict, List, Optional

from .clients import Clients, get_clients
from .deduplication import first_occurrence_map
from .retrieval import NUM_CONTEXT_CHUNKS, retrieve_chunks
from .retry import with_retry

HYBRID_POOL_MULTIPLIER = 4
HYBRID_MIN_POOL = 15
RRF_K = 60   # damping constant from the original Cormack et al. (2009) RRF paper


def _as_or_query(question: str) -> str:
    """websearch_to_tsquery treats unquoted words as an implicit AND, so a full natural-language question
    (~10 words) matches NO chunk. Join the words with the literal OR keyword instead; ts_rank_cd then ranks
    chunks matching more/rarer terms higher. Strip leading/trailing punctuation only (keep '0.8', 'g/kg')."""
    tokens = [tok.strip(string.punctuation) for tok in re.split(r"\s+", question.strip())]
    tokens = [tok for tok in tokens if tok]
    return " OR ".join(tokens) if tokens else question


def retrieve_chunks_keyword(question: str, match_count: int = NUM_CONTEXT_CHUNKS, *,
                            filter_owner: Optional[str] = None, clients: Optional[Clients] = None) -> list:
    clients = clients or get_clients()
    params = {"query_text": _as_or_query(question), "match_count": match_count}
    if filter_owner is not None:
        params["filter_owner"] = filter_owner
    resp = with_retry(lambda: clients.supabase.rpc("match_rag11_child_chunks_keyword", params).execute())
    return resp.data      # may be short or empty (unlike vector search, which always returns K neighbors)


def reciprocal_rank_fusion(ranked_lists: Dict[str, List[dict]], *, k: int = RRF_K, key: str = "rowGUID") -> list:
    """rrf_score(row) = sum over lists L containing row of 1 / (k + rank_L(row)), rank 1-based.
    Returns shallow copies of each row's FIRST occurrence with '<name>_rank' (None if absent from that list)
    and 'rrf_score', sorted by rrf_score descending. Doesn't care whether the lists came from different
    search methods (hybrid) or the same method run on different sub-questions (multi-query)."""
    rows_by_key = first_occurrence_map((row for ranked in ranked_lists.values() for row in ranked), key=key)
    scores: Dict[object, float] = {}
    per_list_rank: Dict[str, Dict[object, int]] = {name: {} for name in ranked_lists}
    for name, ranked in ranked_lists.items():
        for rank, row in enumerate(ranked, start=1):
            per_list_rank[name][row[key]] = rank
            scores[row[key]] = scores.get(row[key], 0.0) + 1.0 / (k + rank)
    fused = []
    for row_key, score in scores.items():
        row_copy = dict(rows_by_key[row_key])
        row_copy["rrf_score"] = score
        for name in ranked_lists:
            row_copy[f"{name}_rank"] = per_list_rank[name].get(row_key)
        fused.append(row_copy)
    fused.sort(key=lambda r: r["rrf_score"], reverse=True)
    return fused


def hybrid_search(question: str, match_count: int = NUM_CONTEXT_CHUNKS, *, dense_pool: Optional[int] = None,
                  keyword_pool: Optional[int] = None, rrf_k: int = RRF_K,
                  filter_owner: Optional[str] = None, clients: Optional[Clients] = None) -> list:
    """Over-fetch max(match_count*4, 15) from EACH method, fuse with RRF, keep match_count.
    Rows carry 'dense_rank', 'keyword_rank' (either may be None) and 'rrf_score'."""
    clients = clients or get_clients()
    pool = max(match_count * HYBRID_POOL_MULTIPLIER, HYBRID_MIN_POOL)
    dense_rows = retrieve_chunks(question, match_count=dense_pool or pool, filter_owner=filter_owner, clients=clients)
    keyword_rows = retrieve_chunks_keyword(question, match_count=keyword_pool or pool, filter_owner=filter_owner, clients=clients)
    fused = reciprocal_rank_fusion({"dense": dense_rows, "keyword": keyword_rows}, k=rrf_k)
    return fused[:match_count]

rerunk_code.py (rerank + manual override)

Why: dense retrieval embeds question and chunk independently — a rough proxy. A cross-encoder reads the (question, chunk) pair together and scores how well this chunk answers this question. Slower, far more precise. Pattern: cast a wide cheap net, then rerank down.

from typing import Optional

def rerank_chunks(question: str, chunks: list, top_n: Optional[int] = None, *,
                  model: str = RERANK_MODEL, clients: Optional[Clients] = None) -> list:
    """Return shallow copies reordered best-first, each with 'rerank_score' (Voyage relevance) and
    'retrieval_rank' (1-based position BEFORE reranking). top_n defaults to len(chunks)."""
    if not chunks:
        return []
    clients = clients or get_clients()
    documents = [row["rowJSON"]["text"] for row in chunks]
    n = top_n if top_n is not None else len(chunks)

                      top_k=min(n, len(documents)))
    reranked = []
    for result in resp.results:
        row_copy = dict(chunks[result.index])
        row_copy["rerank_score"] = result.relevance_score
        row_copy["retrieval_rank"] = result.index + 1
        reranked.append(row_copy)
    return reranked


def update_rank_value(chunks: list, row_guid: str, new_value: float, *, reason: Optional[str] = None,
                      resort: bool = True, persist: bool = False, clients: Optional[Clients] = None) -> list:
    """A human overrides ONE chunk's relevance score. Client-side and in-memory by default (no schema change):
    sets 'manual_rank_score' (+ 'manual_rank_reason') on a copy of the matching row, returns a NEW list.
    Sort precedence when resort=True: manual_rank_score > rerank_score > cosine_distance (ascending).
    Raises ValueError if row_guid isn't in `chunks` (it reorders what you retrieved; it doesn't fetch by id).
    persist=True additionally merges the patch into that row's rowJSON in Supabase via two round trips
    (select rowJSON, then update with the merged dict -- supabase-py's update() takes a full jsonb value);
    needs a key with UPDATE rights (service_role)."""
    updated, found, patch = [], False, None
    for row in chunks:
        row_copy = dict(row)
        if row_copy.get("rowGUID") == row_guid:
            row_copy["manual_rank_score"] = new_value
            patch = {"manual_rank_score": new_value}
            if reason is not None:
                row_copy["manual_rank_reason"] = reason
                patch["manual_rank_reason"] = reason
            found = True
        updated.append(row_copy)
    if not found:
        raise ValueError(f"No chunk with rowGUID={row_guid!r} in the given list -- update_rank_value() only "
                         f"reorders what you already retrieved, it doesn't fetch a chunk by id.")
    if resort:
        def sort_key(row):
            if "manual_rank_score" in row:
                return -row["manual_rank_score"]
            if "rerank_score" in row:
                return -row["rerank_score"]
            return row.get("cosine_distance", 0.0)
        updated.sort(key=sort_key)
    if persist:
        clients = clients or get_clients()
        current = with_retry(lambda: clients.supabase.table("rag11_chunks_child_table")
                             .select("rowJSON").eq("rowGUID", row_guid).single().execute())
        merged = {**current.data["rowJSON"], **patch}
        with_retry(lambda: clients.supabase.table("rag11_chunks_child_table")
                   .update({"rowJSON": merged}).eq("rowGUID", row_guid).execute())
    return updated

Why: one query can only point in one direction in embedding space. "How does soluble fiber's effect on LDL differ from insoluble fiber's?" is secretly two questions; one blurry embedding under-matches both. Split with Claude, search once per sub-question, fuse with the same RRF.

def split_into_subquestions(question: str, *, model: str = GENERATION_MODEL, max_tokens: int = MULTI_QUERY_MAX_TOKENS,
                            max_subquestions: int = MAX_SUBQUESTIONS, clients: Optional[Clients] = None) -> List[str]:
    """ALWAYS returns a non-empty list: an atomic question, an empty reply, or an unparseable reply
    all fall back to [question]. Output beyond max_subquestions lines is truncated."""
    clients = clients or get_clients()
    resp = with_retry(lambda: clients.anthropic.messages.create(
        model=model, max_tokens=max_tokens, system=MULTI_QUERY_SYSTEM_PROMPT,
        messages=[{"role": "user", "content": question}]))
    raw = "".join(block.text for block in resp.content if block.type == "text").strip()
    subs = []
    for line in raw.splitlines():
        m = _SUBQ_LINE_RE.match(line)
        if m:
            subs.append(m.group(1).strip())
    return subs[:max_subquestions] or [question]


def retrieve_chunks_multi_query(question: str, match_count: int = NUM_CONTEXT_CHUNKS, *,
                                retrieve_fn: Callable[..., list] = retrieve_chunks,

                                max_subquestions: int = MAX_SUBQUESTIONS, split_model: str = GENERATION_MODEL,
                                filter_owner: Optional[str] = None, return_subquestions: bool = False,
                                clients: Optional[Clients] = None) -> Union[list, Tuple[list, List[str]]]:
    """retrieve_fn is any (question, match_count, *, filter_owner, clients) function, e.g. retrieve_chunks or
    hybrid_search. Rows carry 'sub1_rank', 'sub2_rank', ... and 'rrf_score'. A question that isn't split still
    goes through RRF with one list (harmless; keeps the return shape uniform)."""
    clients = clients or get_clients()
    subs = split_into_subquestions(question, model=split_model, max_subquestions=max_subquestions, clients=clients)
    pool = per_query_pool or max(match_count * MULTI_QUERY_POOL_MULTIPLIER, MULTI_QUERY_MIN_POOL)
    ranked = {f"sub{i}": retrieve_fn(sq, match_count=pool, filter_owner=filter_owner, clients=clients)
              for i, sq in enumerate(subs, start=1)}
    rows = reciprocal_rank_fusion(ranked, k=rrf_k)[:match_count]
    return (rows, subs) if return_subquestions else rows

parent_chunk_expansion.py ("small-to-big")

Why: child chunks are small (~400 tokens) so they match precisely, but a 2-sentence winner may not contain the whole comparison. Every child's rowParentGUID is a real FK to its parent section: after retrieval, swap each winning child's text for its parent's text so Claude sees the whole section. Small chunk finds the needle; the parent gives the haystack around it.

# context budget shared by all excerpts (~1500 tokens at ~4 chars/token).
DEFAULT_MAX_PARENT_CHARS = 6000


def _truncate(text: str, max_chars: Optional[int]) -> str:
    if max_chars is None or len(text) <= max_chars:
        return text
    return text[:max_chars].rstrip() + "\n\n...[parent chunk truncated for length]"


def expand_to_parent_chunks(chunks: List[dict], *, max_parent_chars: Optional[int] = DEFAULT_MAX_PARENT_CHARS,
                            clients: Optional[Clients] = None) -> List[dict]:
    """Put this LAST (after retrieval/hybrid/rerank). Children sharing a rowParentGUID collapse into ONE row
    (parent fetched and sent once). The surviving row is a shallow copy of the FIRST (best-ranked) matching
    child, so its ranking fields (rerank_score, rrf_score, cosine_distance, dense_rank, ...) survive. Adds:
    'matched_children' (all input rows pointing at this parent), 'expanded_from_parent' (True once rowJSON/text
    was swapped; False only if the parent row is somehow missing -- then the child is kept as-is, never dropped)
    and 'parent_row_guid'. Order = first time each distinct parent is seen. Query-time only; nothing written."""
    if not chunks:
        return []
    clients = clients or get_clients()
    expanded = []
    for parent_guid, matched_children in group_by_key(chunks, key="rowParentGUID").items():
        parent_row = read_parent_row(parent_guid, clients=clients)
        row = dict(matched_children[0])
        row["matched_children"] = matched_children
        if parent_row is None:
            row["expanded_from_parent"] = False
        else:
            row["rowJSON"] = dict(parent_row["rowJSON"])
            row["rowJSON"]["text"] = _truncate(parent_row["rowJSON"]["text"], max_parent_chars)
            row["parent_row_guid"] = parent_row["rowGUID"]
            row["expanded_from_parent"] = True
        expanded.append(row)
    return expanded


def build_expanded_context_block(chunks: List[dict]) -> str:

    parts = []
    for i, row in enumerate(chunks, start=1):
        source_key = row["rowJSON"].get("source_key", row["rowOwnerGUID"])
        label = f"[Excerpt {i} -- {source_key}"
        title = row["rowJSON"].get("title")
        if title:
            label += f" | {title}"
        if row.get("expanded_from_parent"):
            n = len(row.get("matched_children", []))
            label += f" | expanded from {n} matched chunk{'s' if n != 1 else ''}"
        if "rerank_score" in row:
            label += f" | relevance {row['rerank_score']:.2f}"
        label += "]"
        parts.append(f"{label}\n{row['rowJSON']['text']}")
    return "\n\n".join(parts)

def grounding_words(answer_text: str, chunks: list, top_n: int = 12) -> list:
    """A checkable answer to 'what words is this answer established on': words shared by the answer and its
    source excerpts. Drop stopwords and tokens <= 2 chars; lowercase; dedupe; keep first-appearance order in
    the ANSWER; cap at top_n."""
    excerpt_words = {w.lower() for w in _WORD_RE.findall(" ".join(r["rowJSON"]["text"] for r in chunks)) if len(w) > 2}
    seen, shared = set(), []
    for word in _WORD_RE.findall(answer_text):
        lower = word.lower()
        if lower in _STOPWORDS or len(lower) <= 2 or lower in seen:
            continue
        if lower in excerpt_words:
            seen.add(lower)
            shared.append(lower)
        if len(shared) >= top_n:
            break
    return shared

Known pitfalls (learned the hard way — avoid them)

  1. NUL bytes. Some PDFs yield a literal from a bad font stream. Postgres text/jsonb cannot store it (APIError 22P05). Strip \x00 in extract_pages and again right before every upsert; make 22P05 non-retryable.
  2. Generated columns cannot reference other generated columns (Postgres error 42P17), so chunk_tsv is built from "rowJSON"->>'text', not from chunk_text.
  3. create table if not exists never adds columns to an existing table. Add chunk_tsv with an explicit idempotent alter table ... add column if not exists.
  4. RPC overloads. A leftover overload with a different argument type (e.g. filter_owner text) makes PostgREST fail with PGRST203. Drop old signatures explicitly before create or replace function.
  5. websearch_to_tsquery ANDs unquoted words, so a full question matches nothing. OR the words (_as_or_query).
  6. The RPCs cap at 50 rows (limit least(match_count, 50)); over-fetch pools larger than 50 are silently clipped.
  7. Upserts don't delete. After changing section detection, sections that no longer exist stay behind as orphans (stage 1.9 flags them). Use sql/delete_chunks_data.sql, and also delete stage1_eda_output/_checkpoints/, otherwise stage 1.2 skips rows it believes are loaded.
  8. Stale output files. write_chunks must delete old parent_chunk-*.json / child_chunk-*.json first.
  9. pdfplumber can hang forever on rare pages; per-page SIGALRM budget and skip-on-any-exception (section 9.2).
  10. macOS [Errno 35] Resource temporarily unavailable during upserts = open-file-limit pressure. Keep Supabase upserts sequential (SUPABASE_MAX_WORKERS = 1), and offer stage1_0_run_mac_settings.command.
  11. Embedding asymmetry. Chunks and HyDE paragraphs → input_type="document"; questions → input_type="query". Mixing them up silently degrades retrieval.
  12. Dimension coupling. voyage-3 = 1024; the SQL vector(1024) (column + both RPCs), EMBEDDING_DIM, and the verifier must agree.
  13. PostgREST returns pgvector as a list or a string; the verifier must handle both.
  14. Order-preserving parallel embedding. Store batch results by index, not by completion order.
  15. Page-number conventions differ: parent JSON start_page/end_page are 0-based; child headers are 1-based. Keep that in mind (and see the quirk noted under page_numbers_for_expanded_chunk).
  16. Feature-flag priority in ask_question: multi-query > hybrid > HyDE > plain; HyDE is ignored whenever hybrid or multi-query is on. Rerank and parent expansion compose with any of them.
  17. Smoke-cap trap. MAX_NUMBER_OF_PAGES_TO_USE = 100 produces empty text for later sections. Fine for testing code paths; it is not a real run. Tell the user to set it to None for production ingestion.
  18. Running headers/footers in regex-based sources create hundreds of fake sections (one book dropped from 426 to 77 sections after the header fix). Always sanity-check section counts against the expected chapter count.
  19. fitz prints a deprecation warning on new PyMuPDF; import pymupdf is the modern spelling — either works, be consistent.
  20. The wide-open RLS policies and grant ... to anon are for a proof of concept only; flag this to the user as something to tighten before production.
