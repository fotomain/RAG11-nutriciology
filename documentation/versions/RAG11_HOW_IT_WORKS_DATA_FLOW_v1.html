How RAG11 works, end to end

RAG11 is a hierarchical Retrieval-Augmented Generation pipeline over clinical nutrition textbooks: parent/child chunking, Voyage AI domain embeddings, Supabase pgvector with an HNSW index, and Claude Sonnet for grounded, citation-backed answers. This page traces the data as it moves through every stage, from source PDF to final answer.

5 pipeline stages
3 Supabase tables
1024‑dim Voyage‑3 embeddings
HNSW cosine vector index
Claude Sonnet grounded generation

System architecture

Two lifecycles share the same store: an offline ingestion path (top) that builds the knowledge base once, and an online question-answering path (bottom) that queries it on every question.

Stage 1.0 is optional and idempotent (skips any source PDF already cached locally). Stages 1.1 → 1.9 run once to build the knowledge base; stage 2 runs once per question against the store that 1.9 verified.

Database schema

All three tables share one 5‑column shape — rowGUID, rowOwnerGUID, rowParentGUID, orderInList, rowJSON — so the hierarchy (source → parent chunk → child chunk) is encoded the same way at every level, with a few columns pulled out of rowJSON as generated columns for cheap filtering. rowJSON itself stays the single source of truth. 

erDiagram
    rag11_data_sources ||--o{ rag11_chunks_parent_table : "rowOwnerGUID"
    rag11_chunks_parent_table ||--o{ rag11_chunks_child_table : "rowParentGUID"
    rag11_data_sources ||--o{ rag11_chunks_child_table : "rowOwnerGUID (inherited)"

    rag11_data_sources {
      uuid rowGUID PK
      uuid rowOwnerGUID "== rowGUID, self-owned"
      uuid rowParentGUID "always null"
      int orderInList
      jsonb rowJSON
    }
    rag11_chunks_parent_table {
      uuid rowGUID PK
      uuid rowOwnerGUID FK "-> rag11_data_sources"
      uuid rowParentGUID "reserved, null today"
      int orderInList
      jsonb rowJSON
    }
    rag11_chunks_child_table {
      uuid rowGUID PK
      uuid rowOwnerGUID FK "-> rag11_data_sources"
      uuid rowParentGUID FK "-> parent_table"
      int orderInList
      jsonb rowJSON
      vector embedding "1024-dim, Voyage-3"
    }

HNSW cosine index idx_rag11_child_embedding_hnsw (m=16, ef_construction=64) makes match_rag11_child_chunks(query_embedding, match_count=8, filter_owner=null) a fast approximate nearest-neighbor search over the child table, capped at 50 results; get_rag11_parent(rowGUID) expands a matched child back to its full section.
